# API tour

A guided tour of everything [`IsoWeek`](../api/isoweek.md) and [`IsoWeekDate`](../api/isoweekdate.md) can do, grouped by
kind of operation. Every output on this page is generated by running the code shown.

If you are new to the library, work through the [quickstart](quickstart.md) first. For signatures, argument types and
raised exceptions, see the API reference pages for [`IsoWeek`](../api/isoweek.md) and
[`IsoWeekDate`](../api/isoweekdate.md).

The two classes share most of their behaviour through their common parent class `BaseIsoWeek`, so this page covers the
shared operations first and the class specific ones afterwards.

Both classes are available from the top-level module:

```python exec="true" source="material-block" session="tour" result="python"
from datetime import date, datetime

from iso_week_date import IsoWeek, IsoWeekDate

iw = IsoWeek("2023-W01")
iwd = IsoWeekDate("2023-W01-1")

print(iw, iwd)
```

`str()` returns the value, while `repr()` also reports the offset:

```python exec="true" source="material-block" session="tour" result="python"
print(str(iw))
print(repr(iw))
```

## Parsing from other types

An instance can be initialized from several types:

=== "directly"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(IsoWeek("2023-W01"))
    print(IsoWeekDate("2023-W01-1"))
    ```

=== "`from_string`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(IsoWeek.from_string("2023-W01"))
    print(IsoWeekDate.from_string("2023-W01-1"))
    ```

=== "`from_compact`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(IsoWeek.from_compact("2023W01"))
    print(IsoWeekDate.from_compact("2023W011"))
    ```

=== "`from_date`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(IsoWeek.from_date(date(2023, 1, 2)))
    print(IsoWeekDate.from_date(date(2023, 1, 2)))
    ```

=== "`from_datetime`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(IsoWeek.from_datetime(datetime(2023, 1, 2, 12)))
    print(IsoWeekDate.from_datetime(datetime(2023, 1, 2, 12)))
    ```

=== "`from_values`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(IsoWeek.from_values(year=2023, week=1))
    print(IsoWeekDate.from_values(year=2023, week=1, weekday=1))
    ```

=== "`from_today`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(IsoWeek.from_today() == IsoWeek.from_date(date.today()))
    ```

!!! warning "The compact format has no separators"
    The compact format drops _every_ separator: `IsoWeekDate.from_compact` expects **YYYYWNND** (e.g. `"2023W011"`),
    not `"2023W01-1"`. `from_today` also accepts an optional `time_zone` argument.

## Converting to other types

In the opposite direction, an instance can be converted to multiple types:

=== "`to_string`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw.to_string())
    print(iwd.to_string())
    ```

=== "`to_compact`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw.to_compact())
    print(iwd.to_compact())
    ```

=== "`to_date`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw.to_date())
    print(iwd.to_date())
    ```

=== "`to_datetime`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw.to_datetime())
    print(iwd.to_datetime())
    ```

=== "`to_values`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw.to_values())  # (year, week)
    print(iwd.to_values())  # (year, week, weekday)
    ```

!!! warning "IsoWeek to date/datetime"
    [`IsoWeek.to_date`](../api/isoweek.md#iso_week_date.isoweek.IsoWeek.to_date) and
    [`IsoWeek.to_datetime`](../api/isoweek.md#iso_week_date.isoweek.IsoWeek.to_datetime) accept an optional `weekday`
    argument, which defaults to `1` (first weekday), and can be used to get the date of a specific day of the week:

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw.to_date(2))
    print(iw.to_datetime(3))
    ```

    `IsoWeekDate` already carries a weekday, so its `to_date` and `to_datetime` take no argument.

## Comparison operations

Both classes implement all the comparison operators (`==`, `!=`, `<`, `<=`, `>`, `>=`) for instances of the same class:

```python exec="true" source="material-block" session="tour" result="python"
print(iw == IsoWeek("2023-W01"))
print(iw < IsoWeek("2023-W02"))
print(iwd > IsoWeekDate("2023-W02-2"))
```

Comparing across classes is rejected, because an `IsoWeek` and an `IsoWeekDate` do not represent the same kind of
quantity:

```python exec="true" source="material-block" session="tour" result="python"
print(iw == iwd)  # equality is False rather than an error

try:
    iw < iwd
except TypeError as e:
    print(f"TypeError: {e}")
```

Ordering works by first checking that both operands share the same class and the same offset, then comparing their
string values, which is correct because the ISO week date format is lexicographically ordered. See
[why iso-week-date?](why-iso-week-date.md) for why that holds.

### Predicates

The comparison operators also come in a named form, which reads better inside filters, and include a bounded check:

=== "`is_before` / `is_after`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw.is_before(IsoWeek("2023-W02")))
    print(iw.is_after(IsoWeek("2022-W52")))
    ```

=== "`is_between`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw.is_between(IsoWeek("2022-W52"), IsoWeek("2023-W02")))
    print(iw.is_between(IsoWeek("2023-W01"), IsoWeek("2023-W02"), inclusive="neither"))
    ```

`is_between` accepts `inclusive="both"` (the default), `"left"`, `"right"` or `"neither"`.

## Addition and subtraction

!!! danger "operations with `int`s"
    The two classes treat the `int` type differently in addition and subtraction:

    * for `IsoWeek` it is interpreted as **weeks**
    * for `IsoWeekDate` it is interpreted as **days**

Adding an `int` shifts the value; adding an iterable of `int`s returns a generator of shifted values:

=== "Addition `+`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw + 1)
    print(tuple(iw + (1, 2, 3)))
    print(iwd + 1)
    ```

=== "Subtraction `-`"

    ```python exec="true" source="material-block" session="tour" result="python"
    print(iw - 1)
    print(iw - IsoWeek("2022-W52"))  # distance as int
    print(tuple(iw - (1, 2, 3)))
    print(iwd - 1)
    print(iwd - IsoWeekDate("2022-W52-3"))
    ```

Subtracting another instance of the same class returns the distance between the two as an `int`: weeks for `IsoWeek`,
days for `IsoWeekDate`.

The operators are also available as the named methods `add` and `sub`, which accept exactly the same arguments and are
handier when passed around as callables:

```python exec="true" source="material-block" session="tour" result="python"
print(iw.add(2))
print(iw.sub(2))
print(tuple(iw.add((1, 2))))
```

### Stepping by one

For the common case of moving a single step, use `next` and `previous`:

```python exec="true" source="material-block" session="tour" result="python"
print(iw.next(), iw.previous())
print(iwd.next(), iwd.previous())
```

Both classes also implement `__next__`, so the `next()` builtin works on an instance. It returns a **new** object rather
than advancing the existing one:

```python exec="true" source="material-block" session="tour" result="python"
print(next(iw), iw)
```

## Replacing components

`replace` returns a new instance with some components swapped out, leaving the others untouched. Its arguments are
keyword-only:

```python exec="true" source="material-block" session="tour" result="python"
print(iw.replace(year=2024))
print(iwd.replace(week=2, weekday=5))
```

## Ranges

`range` is a classmethod that generates every value between two endpoints, with a configurable step and inclusiveness.
Endpoints can be passed as strings, dates, datetimes or instances:

```python exec="true" source="material-block" session="tour" result="python"
_range = IsoWeek.range(
    start="2023-W01", end="2023-W07", step=2, inclusive="both", as_str=True
)
print(tuple(_range))
```

```python exec="true" source="material-block" session="tour" result="python"
_range = IsoWeekDate.range(
    start="2023-W01-1", end="2023-W03-3", step=3, inclusive="left", as_str=True
)
print(tuple(_range))
```

`as_str=False` yields class instances instead of strings, and `inclusive` accepts the same four values as `is_between`.

## `IsoWeek` specific

### `days` property and `nth` method

`days` returns the tuple of `date`s in the week, and `nth` picks one of them (1-indexed, Monday first):

```python exec="true" source="material-block" session="tour" result="python"
print(iw.days)
print(iw.nth(1), iw.nth(7))
```

### `weeksout` method

`weeksout` generates the weeks that are up to _n\_weeks_ after the given week:

```python exec="true" source="material-block" session="tour" result="python"
print(tuple(iw.weeksout(3)))
print(tuple(iw.weeksout(6, step=2, as_str=False)))
```

### `contains` method and `in` operator

`contains` checks whether a week, string, date or datetime (or an iterable of them) falls inside the given week:

```python exec="true" source="material-block" session="tour" result="python"
print(iw.contains("2023-W01"))
print(iw.contains(date(2023, 1, 1)))
print(iw.contains((IsoWeek("2023-W01"), date(2023, 1, 1), date(2023, 1, 2))))
```

A single value is also accepted by the `in` operator, via `__contains__`:

```python exec="true" source="material-block" session="tour" result="python"
print(date(2023, 1, 1) in iw)
print(date(2023, 1, 2) in iw)
```

## `IsoWeekDate` specific

### `weekday` and `isoweek` properties

```python exec="true" source="material-block" session="tour" result="python"
print(iwd.weekday)  # 1 is Monday, 7 is Sunday
print(iwd.isoweek)  # the week this date belongs to, as a string
```

!!! note "`day` is a deprecated alias"
    `IsoWeekDate.day` still works as an alias of `weekday`, kept for backward compatibility. Prefer `weekday` in new
    code.

### `daysout` method

`daysout` generates the dates that are up to _n\_days_ after the given date:

```python exec="true" source="material-block" session="tour" result="python"
print(tuple(iwd.daysout(3)))
print(tuple(iwd.daysout(6, step=3, as_str=False)))
```
